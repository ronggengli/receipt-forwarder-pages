Privacy Policy / 隱私權政策

Last updated / 最後更新：2026-10-06

English

receipt-forwarder is a personal tool used only by its owner, with the owner's own Google account.

  • Access requested: gmail.readonly (to find specific monthly receipt emails from fixed senders in the owner's own mailbox) and gmail.send (to forward those receipts and send failure notices).
  • Data use: Email data is used only to locate and forward those receipts. Nothing else in the mailbox is processed.
  • Storage: OAuth tokens, a list of processed message IDs, and logs are stored only on the owner's own computer. No data is uploaded to any server operated by the developer.
  • Sharing: Data is not sold, shared with, or transferred to any third party. The only transfer is forwarding receipt emails to the recipient chosen by the owner.
  • Google API Services User Data Policy: The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Other users: There are none. The app is not offered to the public.
  • Revoking access: The owner can revoke access at any time at myaccount.google.com/permissions.

中文

receipt-forwarder 是僅供擁有者本人、以自己的 Google 帳號使用的個人工具。

  • 存取權限：gmail.readonly（在擁有者自己的信箱中，從固定寄件者尋找特定月度單據信件）與 gmail.send（轉寄單據及寄送失敗通知）。
  • 資料用途：信件資料僅用於尋找並轉寄上述單據，不處理信箱中的其他內容。
  • 儲存方式：OAuth 權杖、已處理信件 ID 清單與日誌僅存放於擁有者自己的電腦，不會上傳到開發者營運的任何伺服器。
  • 分享：不出售、不分享、不移轉給任何第三方；唯一的傳送是將單據信件轉寄給擁有者指定的收件人。
  • Google API 服務使用者資料政策：本工具對 Google API 取得資料的使用，遵守 Google API Services User Data Policy，包含有限使用（Limited Use）規定。
  • 其他使用者：無，本應用程式不對外提供。
  • 撤銷授權：擁有者可隨時至 myaccount.google.com/permissions 撤銷。
